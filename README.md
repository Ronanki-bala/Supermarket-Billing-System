# 🛒 Supermarket Billing System

## 📌 Project Overview
The Supermarket Billing System is a Python-based application designed to manage product selection, shopping cart operations, and automatic bill generation. It calculates the subtotal, GST, and final payable amount for customers.

## ✨ Features
- Display available products and prices.
- Add products to the shopping cart.
- Select product quantities.
- Automatically calculate item totals.
- Calculate GST at 12%.
- Generate customer bills.
- Display date and time on the bill.
- Handle invalid user inputs.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Modules:** datetime
- **Concepts:** Functions, Dictionaries, Loops, Conditional Statements, Exception Handling.
